# Security Policy

## Reporting vulnerabilities

Do not report potentially exploitable vulnerabilities in a public issue. Use the private vulnerability-reporting mechanism configured for the GitHub repository.

Include:

- affected component and version
- reproduction steps
- expected and actual behavior
- impact and suggested mitigation
- environment details without secrets or private data

## Supported status

ECommerceOps-Agent is a reference implementation and demo. Production deployments must complete the checklist in [deployment documentation](docs/deployment.md), replace demo authentication, and harden credentials, database privileges, approval storage, audit storage, network access, and identity integration.
