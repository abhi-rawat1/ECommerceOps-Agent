# Roadmap

## Near term

- Clean public-repository and secret-scanning setup
- Cross-platform local setup and Docker validation
- CI for tests and security checks
- Isolated test databases and fixtures
- Hashed passwords and mandatory production JWT configuration
- Structured approval and audit database storage

## Medium term

- Enterprise identity, SSO, and fine-grained RBAC
- Approval policies and configurable action limits
- Immutable audit export
- Workflow retries and idempotency
- Multi-tenant support
- Async background processing for external commerce systems

## Long term

- MCP or tool-provider integrations
- Policy-driven multi-agent orchestration
- Fraud, inventory, and refund-risk models
- Streaming traces and real-time operational alerts
- Pluggable e-commerce and warehouse providers
- Production plugin and deployment packaging
